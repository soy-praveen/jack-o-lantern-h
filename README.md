# The Jack-o'-Lantern H: Carved in One Shot

An entry for the Handshake AI Skills Studio Halloween logo challenge: Handshake's H, carved into a lime pumpkin, with a 3D easter egg.

**Live site:** https://soy-praveen.github.io/jack-o-lantern-h/

- **The logo:** a flat app icon in Handshake's lime and dark teal. The carved H keeps the real shape and slant. See `logo/` (PNG and SVG).
- **The easter egg:** click the icon and a 3D pumpkin pops out, takes an invisible shot, and the H bursts out of it in chunks. See `media/easter-egg.mp4`.
- **Carve it yourself:** `carve.html` is the interactive three.js version. Drag to spin it 360°, then take the shot. It's a single file that loads three.js from a CDN.

Made with ChatGPT (the 2D logo) and Claude + three.js (the 3D model, the animation and the video). This is not an official Handshake page.
